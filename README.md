# 🏥 SisFarma PRO — Sistema Integral de Gestión Farmacéutica

**SisFarma PRO** es una aplicación web moderna, ágil y reactiva para la gestión integral de farmacias, control de inventario, punto de venta (POS) y facturación simplificada. Diseñada con una arquitectura *Single-File App*, permite ser desplegada instantáneamente en servicios como **GitHub Pages** sin necesidad de compilación previa o backend complejo.

---

## 🌟 Características Principales

- 🛒 **Punto de Venta (POS) Interactivo:**
  - Búsqueda en tiempo real por código CNAV, nombre comercial o principio activo.
  - Soporte para recetas médicas electrónicas y cálculo automático de IVA sanitario (4%).
  - Modalidades de pago flexibles (Efectivo, Tarjeta, Mutua / Seguro).
  - Impresión de tickets y facturas simplificadas.

- 📦 **Control de Inventario y Stock:**
  - Registro dinámico de medicamentos, números de lote y fechas de caducidad.
  - Sistema de alerta visual para productos en stock crítico o agotados.
  - Filtros avanzados por categoría y estado de catálogo.

- 📊 **Panel de Control y Analítica:**
  - Cuadro de mando con KPIs de ventas del día, productos bajo mínimo y operaciones.
  - Gráficos interactivos integrados con **Chart.js** para visualizar la evolución de ingresos y márgenes por familia farmacológica.

- 🌍 **Soporte Multilingüe (i18n):**
  - Cambio de idioma dinámico instantáneo: **Español, English, Français, Deutsch, Português**.

- 🎨 **Diseño Moderno & Oscuro:**
  - Construido con **Tailwind CSS**, componentes con efecto de cristal (*glassmorphism*) y diseño 100% adaptativo (*responsive*).

## 🚀 Inicio Rápido / Instalación

No requiere instalación de dependencias como Node.js o NPM.

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/sisfarma.git
   ```
2. **Abre el archivo principal:**
   Simplemente abre `sisfarma_sistema_integral_de_gesti_n_farmac_utica.html` (o renómbralo a `index.html`) en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).
